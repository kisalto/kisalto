Sou estudante de **Engenharia de Software** na UniAmérica e atuo como **Software Engineer Intern na Itaipu Parquetec**, trabalhando principalmente com desenvolvimento backend.

Minha experiência envolve **Python, FastAPI, APIs REST, automação de processos, integração de sistemas e testes automatizados**. Também tenho experiência com Java/Spring Boot, desenvolvimento frontend e bancos de dados.
